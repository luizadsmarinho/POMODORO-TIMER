## Sobre o projeto

Este é um cronômetro Pomodoro desenvolvido com HTML, CSS e JavaScript.  
Ele foi criado para ajudar na organização de estudos com uma experiência mais imersiva, usando elementos visuais e sonoros inspirados na natureza.

Durante o foco, há um ambiente de chuva com vídeo, som e animação.  
Durante o descanso, o cenário muda para uma natureza tranquila e sons de pássaros, criando uma sensação de transição natural entre concentração e pausa.

## Funcionalidades

- Timer Pomodoro personalizável  
- Ambiente de chuva no modo foco  
- Ambiente de pássaros no descanso  
- Vídeos de fundo dinâmicos  
- Áudio sincronizado com o estado do timer  
- Animação de chuva em JavaScript  
- Interface simples e responsiva
