# POMODORO-TIMER
Esse projeto é um cronômetro Pomodoro feito com HTML, CSS e JavaScript. Ele alterna entre foco e descanso, com tempos definidos pelo usuário. Durante o foco há chuva e durante o descanso, pássaros, com vídeos, sons e animações sincronizadas para tornar o estudo mais imersivo e agradável.
